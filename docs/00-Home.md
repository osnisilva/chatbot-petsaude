# 🏥 ACS-Online - Base de Conhecimento

Bem-vindo à documentação oficial do projeto **ACS-Online** (Agente Comunitário de Saúde Online).
Este repositório (Obsidian Vault) documenta a arquitetura, o banco de dados, as funcionalidades e os guias de manutenção do sistema.

## 🗂️ Índice

### 🏛️ Arquitetura
- [[Backend]] - Banco de dados (Supabase), Autenticação e Storage.
- [[Frontend]] - Painel web (Next.js, Tailwind CSS).
- [[Bot-WhatsApp]] - Lógica de integração e mensageria.

### ⚙️ Funcionalidades Principais
- [[Painel-Dashboard]] - Visão administrativa geral.
- [[Pacientes-e-Agendamentos]] - Gestão de pacientes e agendamentos.
- [[Equipe-e-Relatorios]] - Gerenciamento de acessos e métricas.
- [[Trilhas-de-Cuidado]] - Sistema de mensagens programadas e geradas por IA.
- [[Chat-e-Mensageria]] - Interface de comunicação e fluxo de envio/recebimento.

### 🔌 Integrações
- [[Integracao-e-SUS]] - Especificação e arquitetura para leitura do e-SUS.

### 🗄️ Banco de Dados
- [[Esquema]] - Estrutura de tabelas e relacionamentos.
- [[Seguranca-e-RLS]] - Row Level Security e adequação à LGPD.

### 📖 Manuais
- [[Configuracao-do-Ambiente]] - Como rodar o projeto localmente.
- [[Perfis-de-Acesso]] - Matriz de permissões (ACS, Gerente, Admin TI).
